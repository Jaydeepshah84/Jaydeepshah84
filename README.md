## Featured projects

### [WorkFlow Arena](https://github.com/Jaydeepshah84/workflowarena): reinforcement learning environment for enterprise workflows

`Python` · `Docker` · `TRL (GRPO)` · `PEFT / LoRA` · `Hugging Face Spaces`

A simulated enterprise environment (Gmail, Slack, Jira, HRIS, CRM, Deploy, Finance) where AI agents learn multi-app workflows. Every reward is verified against an actual API response, with no LLM judge and no subjective grading. Built for the Meta PyTorch OpenEnv Hackathon.

- Tested the reward verifier against 10 reward-hacking attack patterns. The best attack scored 0.17, against 0.99 for a perfect agent.
- Trained agents scored 1.7×–2.3× the random baseline across three workflows.
- Links: [live Space](https://huggingface.co/spaces/jaydeepshah2025/workflow-arena) · [Colab notebook](https://colab.research.google.com/github/Jaydeepshah84/workflowarena/blob/main/train_workflow_arena.ipynb) · [write-up](https://github.com/Jaydeepshah84/workflowarena/blob/main/BLOG.md)

### [Learnify](https://github.com/Jaydeepshah84/Learnify): AI-powered learning platform for Indian learners

`TypeScript` · `Next.js` · `React Native (Expo)` · `Node.js / Express` · `Socket.io` · `Supabase (PostgreSQL)` · `LangChain` · `Python / Flask`

A multi-surface learning platform (web, mobile, backend and a voice service) that uses LLMs to generate complete courses in Hindi, English, Gujarati and Spanish and teaches them with narrated visual lessons.

- Mastery-based progression: lesson tests gate the next lesson.
- Collaborative two-person study rooms built on Socket.io and WebRTC.
- Emotion-adaptive lessons using webcam expression detection (face-api.js), and an offline-first mobile app with a local SQLite cache.
